Informix, Db2 and PostgreSQL in one place.

Prism is a desktop database client for people who work every day with Informix, Db2 and PostgreSQL. The goal is to be faster and more direct than DBeaver on the same tasks: open, connect, browse the objects, run SQL and see the result.

Download Code on GitHub
Early days

Prism is just starting out: the latest stable version is the recommended one, and betas may have defects. The packages are not signed: see how to open them. The interface is currently in Brazilian Portuguese, so this guide gives the labels as they appear on screen, with a translation in parentheses.

What Prism is

It is a desktop app for Windows, macOS and Linux. You connect to the database, browse the objects and run SQL. Each user has an encrypted vault with their folders and connections.

Under the hood, the app (Electron) starts a local API that only listens on 127.0.0.1. The screen talks to it, and it talks to the database.

DatabaseDriverStatus
PostgreSQLShips inside the package.Works.
Db2From IBM. You download it in Configurações › Drivers (Settings › Drivers).Works with Db2 12.1.
InformixThe same IBM driver.Works with Informix 14.10, over the DRDA port.

The database grid also shows SQLite, MySQL, MariaDB, SQL Server, Oracle, Firebird, DuckDB and ClickHouse as “Em breve” (coming soon). Prism cannot connect to them yet.

What you can do today

  • Keep connections in folders, each with an environment (name and color).
  • Browse schemas, tables, views, routines, columns, indexes and foreign keys, with search.
  • Run SQL and see the result in a grid: load more, count the total, cancel.
  • Open a table and see its records (with filter and order), its structure and its diagram.
  • Choose among six themes, light and dark.
  • Download the Db2 and Informix drivers when you need them.
  • Get updates from the GitHub releases, with an optional beta channel.

Download and install

Download from the releases page

Stable or beta. The latest stable version is marked Latest: it is the recommended one. Betas come out on every merge into develop, are marked Pre-release and may have defects.

On the page, open the newest version (the top one) and, under Assets, pick the file for your system. In the names, <version> is the release version, such as 0.1.0 or 0.1.1-beta.1.

Install

  • Windows: open the .exe. Or extract the .zip and open Prism from inside the folder, with no installation.
  • macOS: open the .dmg and drag Prism to the Applications folder.
  • Linux, AppImage: chmod +x the file and open it.
  • Linux, deb: sudo apt install ./Prism-<version>-linux-amd64.deb
  • Linux, rpm: sudo dnf install ./Prism-<version>-linux-x86_64.rpm
  • Linux, tar.gz: extract it and open prism, inside the folder.

On first launch the system warns that the package is not signed. See below how to proceed.

Check the checksum

Every version ships a SHA256SUMS file, with the SHA-256 checksum of all packages, and the same checksums at the end of the release notes. Compute the SHA-256 of the file you downloaded and compare it with its line in SHA256SUMS and in the “Somas SHA-256” block (SHA-256 checksums) of the notes. If it doesn't match, delete the file and download it again.

SystemCommand
Linuxsha256sum <file>
macOSshasum -a 256 <file>
Windows (PowerShell)Get-FileHash -Algorithm SHA256 <file>

No package is signed

Signing the packages comes later. Until then, Windows and macOS warn you on first launch. The warning is expected: check the checksum and go ahead.

  • Windows: SmartScreen shows “Windows protected your PC”. Click More info and then Run anyway.
  • macOS: Gatekeeper blocks unsigned apps. With Prism in the Applications folder, right-click it, choose Open and confirm with Open. On macOS 15 (Sequoia) or newer that is not enough: try to open it once, go to System Settings › Privacy & Security and click Open Anyway.
  • macOS, from the Terminal: works on any version. 
    xattr -dr com.apple.quarantine /Applications/Prism.app
  • Linux: nothing depends on a signature. The AppImage and the tar.gz open without one, and the deb and the rpm install through the package manager.

Did something not work? Open an issue: that is where we fix it.

First use

The first time you open Prism there is no user yet. Create yours:

  1. On the sign-in screen, click Criar usuário (Create user), under “Primeiro acesso?” (First time here?).
  2. Choose the username: 3 to 32 characters, with letters, digits, dot, hyphen and underscore. Prism stores it in lowercase.
  3. Choose the password, 8 to 128 characters, and confirm it.
  4. Click Criar usuário and sign in.
The password generates the vault key and cannot be recovered

Your password is not stored. It generates the key that opens your vault. If you forget it, the saved connections cannot be recovered. Keep the password somewhere safe.

Each user has their own vault: you can have several users on the same machine, and each one opens only their own. Sair (Sign out), in the top bar, closes the vault. To change the password, use Configurações › Conta (Settings › Account).

Connections

Create a connection

  1. Click Nova conexão (New connection), in the browser bar.
  2. Choose the database in the grid and click Avançar (Next).
  3. Fill in the name, the folder, the host, the port, the database, the user and the database password. The port comes suggested: 5432 for PostgreSQL, 50000 for Db2 and 9089 for Informix.
  4. Click Testar conexão (Test connection). The notice says “Conexão testada com sucesso.” (Connection tested successfully.) or “Não foi possível conectar.” (Could not connect.), and the database's message appears below the buttons.
  5. Click Salvar (Save).

Informix is served over the DRDA protocol. Use the server's DRDA port, not the native protocol's.

Folders, environments and passwords

  • Folders. “Nova pasta” (New folder) creates a folder; the folder menu creates subfolders, renames, moves and deletes. Only an empty folder, with no subfolders and no connections, can be deleted. The connection menu has Mover (Move).
  • Environment. The name and the color (red, amber, green, blue, violet, gray or another) identify the connection in the tree and in its tabs. Leave the name blank if the connection does not belong to an environment.
  • Database password. It is stored encrypted in the vault, with your Prism password. When editing a connection, leave the field empty to keep the password. To see the stored password, Prism asks for your password again, and on the fifth wrong attempt in a row the vault closes.
  • Edit and delete. From the connection menu. Deleting removes the connection from the vault, along with the stored password, and closes its sessions and query tabs. The SQL in those tabs is lost.
  • Connect. Double-click the connection, or use Conectar (Connect) in the browser bar. Desconectar (Disconnect) ends its sessions.

Db2 and Informix: the IBM driver

Prism ships only the PostgreSQL driver. The IBM driver, which serves Db2 and Informix, you download when you need it, accepting the vendor's license.

  1. Open Configurações › Drivers (Settings › Drivers) and click Baixar (Download) on the IBM Data Server row.
  2. Read the license. Prism does not open links: copy the address of the official text and read it in your browser.
  3. Check “Li e aceito a licença do fabricante” (I have read and accept the vendor's license) and click Baixar e instalar (Download and install).
  4. Prism downloads the driver from nuget.org, verifies the hash and saves it on your machine.
  5. Then Prism offers to restart the service: “Reiniciar agora” (Restart now) or “Depois” (Later). The restart asks for your password again and closes the open SQL tabs. Until then, the top bar shows “Reinício pendente” (Restart pending).

You can save a Db2 or Informix connection before installing the driver. Only testing and connecting need the driver. “Remover” (Remove) takes the driver off the machine, and the service restarts the same way. IBM does not publish the driver for Macs with an Intel processor: there the grid says “Sem driver para esta plataforma” (No driver for this platform).

Browser and search

The browser, on the left, shows your folders and connections. Once connected, the tree goes down like this:

connection › database › schema › Tabelas, Visões and Rotinas (Tables, Views and Routines) › columns, indexes and foreign keys.

  • Primary key columns carry PK. System schemas are marked “sistema” (system).
  • In Informix, the “schema” is the object's owner.
  • Double-clicking a table or a view opens its tab.
  • Right-click opens the menu: Conectar, Desconectar, Nova consulta, Atualizar, Editar conexão, Abrir registros, Ver estrutura, Ver diagrama, Gerar SELECT, Copiar nome and Copiar nome qualificado (Connect, Disconnect, New query, Refresh, Edit connection, Open records, View structure, View diagram, Generate SELECT, Copy name and Copy qualified name).

Search

The “Filtrar objetos” (Filter objects) field filters what is already loaded in the tree. Open a connection or a schema to search inside it. The result shows the path to each match, with the matching part highlighted and the count.

SQL editor and results

To write SQL, choose Nova consulta (New query) from a connection's menu. Each query is a tab tied to the connection (consulta-1.sql, consulta-2.sql and so on). The text of the tabs is not stored anywhere: when you close the tab or the app, it is lost.

Run

  • Ctrl + Enter (or the Executar (Run) button) sends the selected text. With no selection, it sends the command where the cursor is.
  • A run takes one command only. Commands are separated by ; outside quoted text, comments and PostgreSQL's $tag$ … $tag$. If the selection has more than one, Prism warns you and does not send it.
  • The command goes to the database as it is, without being rewritten, and always in auto-commit (the bottom bar shows “Auto-commit”). Transaction control commands, such as BEGIN, COMMIT and ROLLBACK, are refused.
  • Cancelar (Cancel) interrupts a slow command. The screen says “Comando cancelado.” (Command cancelled.) when it is sure the command did not finish.

The result

  • A command that returns rows shows the first 200 and the time: “Primeiras 200 linhas · 17 ms” (First 200 rows · 17 ms).
  • Carregar mais 200 (Load 200 more) brings the next ones, from the same cursor, without running again.
  • Contar total (Count total) only counts when you ask (“Total: 232 linhas”).
  • If you prefer, turn on “Buscar mais linhas ao rolar até o fim da grade” (Fetch more rows when scrolling to the end of the grid) in Configurações › Resultados (Settings › Results). The total still comes only on request.
  • A command with no rows shows “N linhas afetadas” (N rows affected) and the time.
  • The cursor closes after 5 minutes without reading. Prism tells you, and Executar de novo (Run again) continues.

Cells, columns and zoom

  • The null value appears as NULL (in Configurações › Resultados you can change the text).
  • Text longer than 10,000 characters and binary values arrive truncated. The cell is marked “Valor cortado” (Value truncated), and a notice says that some values were truncated.
  • Each column header shows its type. Drag the divider to change the width, and double-click it to fit the content.
  • The grid zoom goes from 50% to 200%, with the minus and plus buttons or with Ctrl + the mouse wheel over the grid.
  • The result area can be collapsed, maximized or resized.

Errors

The database error reaches the screen as it came: the original message, the SQLSTATE and, on PostgreSQL, the error position underlined in the editor.

Prism does not export the result of a query. CSV export is in the Records of a table.

Records of a table

Double-click a table (or use “Abrir registros” (Open records), in the menu). The table tab has three views: Registros (Records), Estrutura (Structure) and Diagrama (Diagram). The strip on top shows the connection's database, schema and environment.

Records

  • Filter and order. The field accepts what comes after the table name: a condition, an order (ORDER BY) or both. The “Comando” (Command) line shows the SQL that was run.
  • Order by header. One click sorts by that column, the second reverses it and the third removes the order. Prism writes the ORDER BY in the field.
  • Foreign keys. The value of a foreign key is a link: it opens the referenced table, already filtered by that value.
  • More. “Atualizar” (Refresh) reads again, “Contar total” counts, and “Exportar CSV” (Export CSV) writes the loaded rows. Rows not yet loaded are not in the file, and truncated values come out truncated.

Structure

Four sections: Colunas (Columns: name, type, whether it accepts null and the key, PK or FK), Chaves estrangeiras (Foreign keys), Índices (Indexes) and DDL. The DDL is approximate: Prism builds it from the catalog, and it does not include defaults, check constraints or storage options. There is a button to copy it. A view has no DDL.

Diagram

The table and the ones it references, with the arrow leaving the foreign key. You can zoom in, zoom out and fit to the screen, and double-clicking a table in the diagram opens it. Only the tables this one references appear: the ones that point to it do not appear yet.

Settings

Open it with the Configurações (Settings) button, in the top bar, or with Ctrl + ,. Esc closes it. The sections:

  • Conta (Account). Change the password. Prism re-encrypts your vault with the new password.
  • Aparência (Appearance). The theme. Prism ships six: Prism Escuro (Dark), Prism Claro (Light), Monokai, Dracula, Nord and GitHub Claro (Light). The theme applies to the whole interface, and you can follow the system's light or dark mode.
  • Editor SQL (SQL editor). The font, the font size, the tab size, “Autocompletar ao digitar” (Autocomplete as you type) and “Converter palavras-chave para maiúsculas” (Convert keywords to uppercase). Autocomplete uses the database's keywords and the names the tree has already loaded, and never queries the database.
  • Resultados (Results). The null value text (1 to 12 characters) and “Buscar mais linhas ao rolar até o fim da grade”.
  • Segurança (Security). “Bloquear o Prism após” (Lock Prism after) a number of minutes of inactivity. It is on by default, at 10 minutes, and accepts 1 to 240. When locked, the vault closes, and only your password reopens it.
  • Atualizações (Updates). Below.
  • Drivers. See Db2 and Informix.
  • Sobre (About). The version and the data folder, where the vaults and the API log live.
  • Transações (Transactions). Marked “em breve” (coming soon): see below.

Updates and the beta channel

  • On launch, and at most once a day, Prism queries the project's release list on GitHub, with no credentials. If there is a newer version, it shows the notes and asks.
  • It only downloads if you say so (“Atualizar agora”, Update now). You can postpone, skip a version and turn off the check on launch. “Verificar atualizações” (Check for updates) queries right away.
  • The query sends no identifier of you or your machine.
  • Before using the file, Prism checks it against two SHA-256 checksums: the one in the release notes and the one in SHA256SUMS. If one is missing or doesn't match, it deletes the file and refuses the update.
  • On Windows, “Atualizar agora” runs the verified installer, which reopens Prism. On Linux and macOS, Prism leaves the verified package in the downloads folder and tells you what to do.
  • Beta channel. With “Receber versões beta” (Receive beta versions) off, which is the default, Prism only offers stable versions. With it on, it also offers betas, and the dialog warns that the version is a beta and may have defects.

A Prism built on your own machine, or built without the project address, does not look for updates.

Security and privacy

  • Encrypted vault. The folders and the connections (names, hosts, users and database passwords) live in one encrypted file per user. From your password comes, through Argon2id, the key that protects a random vault key, and the content is encrypted with AES-256-GCM. The Prism password is not stored anywhere.
  • When the vault closes. On “Sair” (Sign out), when the app closes, when another user signs in, on the fifth wrong attempt in a row when revealing a password and on the inactivity lock.
  • API only on 127.0.0.1. The local API listens on a port chosen by the system each time the app starts and requires a token generated each time the app starts. Without the token, the response is 401. It accepts a single page origin, and the process ends together with the app.
  • The window. It runs with context isolation and sandbox, with no direct access to Node. The interface can only connect to the local API, and the fonts and images ship inside the app.
  • Log. Prism does not log passwords, connection strings or SQL text. Even so, review the log before attaching it to an issue: it may contain paths from your machine and unexpected error messages.
  • Free software. Prism is GPLv3: it can be used, studied, modified and redistributed, as long as whoever distributes it provides the code under the same license. The code is on GitHub.

What the app reaches over the network

  • The databases you connect to, with the data you provided.
  • The GitHub releases, to look for a new version: on launch, at most once a day.
  • The update package and the driver from nuget.org, only when you tell it to download.

Beyond that, Prism does not talk to the network: there is no telemetry and no account. This page also uses no script, cookie or tracking.

What Prism does not protect: anyone with access to the user's session on the operating system, with the app open and unlocked, is outside the vault's protection.

Where to report

  • Defect or suggestion: open an issue, using the defect or suggestion form. You can write it in English, Portuguese or Spanish. Include the Prism version (it shows on the sign-in screen), the operating system and the database. Never attach a password, a connection string or customer data.
  • Vulnerability: do not use an issue, which is public. On the repository page, open the Security tab and click Report a vulnerability. The step by step is in SECURITY.md.
  • Contributing: read CONTRIBUTING.md.
